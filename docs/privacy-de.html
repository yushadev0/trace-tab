Trace Tab

Datenschutzerklärung

Zuletzt aktualisiert: 7. September 2026

Türkçe · English · Deutsch

Diese Datenschutzerklärung erläutert, wie die Chrome-Erweiterung „Trace Tab“ (die „Erweiterung“) Ihre personenbezogenen Daten verarbeitet. Mit der Installation oder Nutzung der Erweiterung akzeptieren Sie diese Erklärung.

1. Kurzzusammenfassung

  • Wir betreiben keinen Server. Der gesamte Datenfluss findet direkt zwischen Ihrem Browser und den Diensten von Google, Microsoft und Tavily statt; keine Daten laufen über einen von uns kontrollierten Server.
  • Wir tun nichts außer dem Anzeigen Ihrer E-Mails — kein Löschen, Senden, Antworten oder Archivieren. Wir lesen nur Absender / Datum / Betreff / Kurzvorschau Ihrer ungelesenen E-Mails und fassen sie zusammen.
  • Ihre API-Schlüssel (Gemini, Tavily) und OAuth-Sitzungsdaten werden ausschließlich in Ihrem eigenen Browser (chrome.storage.local) gespeichert und niemals an uns oder Dritte weitergegeben.
  • Wir verkaufen Ihre Daten nicht, verwenden sie nicht für Werbung und geben sie nicht zu Marketingzwecken an Dritte weiter.

2. Welche Daten wir verarbeiten

2.1 E-Mail-Daten (Gmail / Outlook)

Wenn Sie Ihr Gmail- oder Outlook-Konto verbinden, liest die Erweiterung nur die folgenden Angaben aus Ihren ungelesenen Posteingangs-E-Mails:

  • Absendername / -adresse
  • Datum
  • Betreff
  • Eine kurze Inhaltsvorschau (Snippet)

Diese Informationen werden an die Google-Gemini-API gesendet, um eine Zusammenfassung der E-Mail in 1–2 Sätzen sowie eine Prioritätsstufe (niedrig / mittel / hoch) zu erzeugen. Die Zusammenfassung wird in der von Ihnen in der Oberfläche gewählten Sprache erstellt (Türkisch, Englisch oder Deutsch). Die erzeugte Zusammenfassung wird nur in Ihrem eigenen Browser (chrome.storage.local) zwischengespeichert, damit dieselbe E-Mail nicht wiederholt zusammengefasst wird. Sie können diesen Cache jederzeit über die Einstellungsseite leeren.

Die Erweiterung löscht, sendet, beantwortet, leitet Ihre E-Mails nicht weiter und ändert sie nicht. Es wird nur Lesezugriff (read-only) verwendet.

Wenn Sie auf eine E-Mail-Karte klicken, wird die betreffende E-Mail oder Ihr Posteingang in einem neuen Tab in der Weboberfläche von Gmail bzw. Outlook geöffnet; dies geschieht vollständig über Ihren Browser.

2.2 KI-Chat (Gemini)

Nachrichten, die Sie mit der Funktion „Schnellfrage“ eingeben, werden direkt aus Ihrem Browser an die Google-Gemini-API gesendet, um eine Antwort zu erzeugen. Ihre vorherigen Nachrichten in einem Gespräch werden bei nachfolgenden Anfragen erneut mitgesendet, um den Kontext zu erhalten. Dieser Gesprächsverlauf wird nur im gerade geöffneten Tab im Browser-Arbeitsspeicher gehalten; er wird gelöscht, sobald Sie den Tab schließen oder einen neuen Tab öffnen, und wird nirgendwo dauerhaft gespeichert.

2.3 Websuche (Tavily)

Wenn Sie die Option „Im Web suchen“ aktivieren, wird Ihre Frage an die Tavily-Such-API gesendet, um aktuelle Ergebnisse abzurufen. Dies geschieht nur, wenn Sie diese Option ausdrücklich aktivieren.

2.4 Lokal gespeicherte Daten

Die folgenden Angaben werden nur in chrome.storage.local auf Ihrem eigenen Computer gespeichert und nicht an uns oder Dritte weitergegeben:

  • Ihre Gemini- und Tavily-API-Schlüssel
  • Gmail-/Outlook-OAuth-Zugriffs- und Aktualisierungstoken (Refresh Token)
  • Darstellungseinstellungen wie gewählte Sprache, Design und Begrüßungstitel / -untertitel
  • Der Cache zuvor zusammengefasster E-Mails

Diese Daten werden nur gelöscht, wenn Sie die Erweiterung deinstallieren oder die betreffende Verbindung / den Cache selbst leeren.

3. Mit wem wir Daten teilen

Wir geben Ihre Daten an keinen Dritten zu Marketing-, Werbe- oder Verkaufszwecken weiter. Damit die Erweiterung funktioniert, kommuniziert sie direkt mit den folgenden Diensten (jeder unterliegt seiner eigenen Datenschutzerklärung):

  • Google — Gmail-API (E-Mail-Lesen), Gemini-API (Zusammenfassung und Chat), Google OAuth (Authentifizierung für die Gmail-Verbindung)
  • Microsoft — Microsoft-Graph-API (Outlook-E-Mail-Lesen), Microsoft-Identitätsplattform (Authentifizierung für die Outlook-Verbindung)
  • Tavily — Such-API, nur wenn die Funktion „Im Web suchen“ verwendet wird

Anfragen an diese Dienste gehen direkt von Ihrem Browser aus; kein Server von uns ist dazwischengeschaltet, da wir keinen haben.

4. Einhaltung der Google-Richtlinie für Nutzerdaten

Die Verwendung und Weitergabe von Informationen, die Trace Tab von Google-APIs erhält, an andere Apps erfolgt in Übereinstimmung mit der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use). Konkret:

  • Gmail-Daten werden ausschließlich für die in Abschnitt 2.1 beschriebene Zusammenfassungsfunktion verwendet.
  • Diese Daten werden keiner menschlichen Überprüfung unterzogen, nicht für Werbung und nicht für Kreditwürdigkeitsprüfung oder Kreditvergabe verwendet.
  • Daten werden nicht länger gespeichert, als für die beschriebene Funktionalität erforderlich ist (siehe Abschnitt 2.4).

5. Datensicherheit

Ihre API-Schlüssel und Sitzungstoken werden in chrome.storage.local gespeichert, beschränkt auf Ihr Browserprofil. Die Outlook-Verbindung verwendet den branchenüblichen PKCE-OAuth-2.0-Ablauf (Proof Key for Code Exchange). Die Erweiterung sendet keine Ihrer Zugangsdaten (Passwort, API-Schlüssel, Token) an unseren Server oder den Server eines Dritten.

6. Verbindung trennen und Daten löschen

  • Sie können die Gmail-/Outlook-Verbindung mit einem Klick auf der Einstellungsseite trennen; dabei wird das lokal gespeicherte Sitzungstoken gelöscht.
  • Sie können den E-Mail-Zusammenfassungs-Cache jederzeit über die Schaltfläche „Cache leeren“ auf der Einstellungsseite löschen.
  • Wenn Sie die Erweiterung aus Chrome entfernen, werden alle Daten in chrome.storage.local (API-Schlüssel, Cache, Einstellungen, Token) automatisch von Chrome gelöscht.

7. Datenschutz für Kinder

Die Erweiterung richtet sich nicht an Kinder unter 13 Jahren und erhebt wissentlich keine Daten von ihnen.

Wir können diese Erklärung von Zeit zu Zeit aktualisieren. Bei wesentlichen Änderungen wird das Datum „Zuletzt aktualisiert“ oben auf dieser Seite angepasst.
